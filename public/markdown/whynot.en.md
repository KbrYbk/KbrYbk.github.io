# Whynot

A landing page that was created at the very beginning of my journey in web development. This is one of my first completed works.

## About the Project
In this project, I first tried to apply the theoretical knowledge I gained in practice. The foundation includes:
* Using **HTML5** to build the document structure.
* Basic styling with **CSS3**.
* Applying the popular **Bootstrap** framework to create a responsive grid.

This project demonstrates my first steps, an understanding of how page markup is built, and attempts to work with external CSS libraries. It is left in the portfolio as the starting point from which everything began.
