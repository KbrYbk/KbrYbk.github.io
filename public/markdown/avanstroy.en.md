# AvanStroy

A landing page for the "AvanStroy" construction company. This project became the next stage in my web development learning path after creating my first simple pages.

## About the Project
In this work, I continued to master layout technologies by applying new knowledge in practice. Inside the project you can see:
* The use of HTML and CSS without third-party UI libraries.
* Working with grids and element positioning (Flexbox).
* Basic page adaptation for different screen resolutions.
* Styling of custom interface elements.

This project is kept in the portfolio as an important milestone, showing the development of my skills and understanding of web interfaces.
