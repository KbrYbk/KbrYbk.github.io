# Whynot

Главная страница, которая была создана в самом начале моего пути в веб-разработке. Это одна из моих первых законченных работ.

## О проекте
В этом проекте я впервые пробовал применять полученные теоретические знания на практике. В основе лежит:
* Использование **HTML5** для построения структуры документа.
* Базовое оформление на **CSS3**.
* Применение популярного фреймворка **Bootstrap** для создания адаптивной сетки.

Этот проект демонстрирует мои первые шаги, понимание того, как строится разметка страницы, и попытки работы с внешними CSS-библиотеками. Он оставлен в портфолио как точка отсчета, с которой всё началось.
