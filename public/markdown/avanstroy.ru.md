# Аванстрой

Лендинг для строительной компании «Аванстрой». Этот проект стал следующим этапом в моем обучении веб-разработке после создания первых простых страниц.

## О проекте
В этой работе я продолжил осваивать технологии верстки, применяя новые знания на практике. Внутри проекта можно увидеть:
* Использование HTML и CSS без сторонних UI-библиотек.
* Работу с сеткой и позиционированием элементов (Flexbox).
* Базовую адаптацию страницы под разные разрешения экранов.
* Стилизацию нестандартных элементов интерфейса.

Этот проект сохранен в портфолио как важный этап, показывающий развитие моих навыков и понимания принципов работы с веб-интерфейсами.
